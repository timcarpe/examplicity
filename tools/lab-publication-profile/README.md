# Lab publication profile

This site-owned release records the constraints an approved source lab must
satisfy when it is published by Examplicity. It is separate from both the
layout-agnostic Lab Creation kit and the mechanical resource compiler.

`profile.json` is the machine-readable contract. `manifest.json` pins its exact
bytes for consumers that need an authoring or preview copy. Canonical changes
happen here; Lab Creation may vendor an immutable release but must not maintain
a competing profile.
