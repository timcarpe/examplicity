# Homepage lab ports

These are excerpts of the real redesigned labs, not illustrations. `*.json` contains the native markup and applicable published CSS; `*.js` retains source rendering functions with only the surrounding application orchestration removed. Shadow roots isolate the source styling, and SVG identifiers/references are namespaced.

Regenerate from the repository root with `node scripts/sync-home-previews.mjs` after syncing a featured source lab to its published output. Pass names to regenerate only selected ports, for example `node scripts/sync-home-previews.mjs packet diffraction gas trig`. Each asset records its source path and SHA-256. Review source visual changes before regenerating; do not hand-edit generated assets.

The homepage rotates through Packet Switching, Diffraction, Gas Compression, Graph Search, Circle Theorem, CPU and Trigonometric Graphs. Packet Switching follows six packets over valid source routes. Diffraction narrows the gap using the original canvas wave renderer and SVG overlay. Gas Compression replays 6 L to 3 L with the original particles, pressure law, gauge and graph. Graph Search replays valid A* steps. Circle Theorem moves C through a 96-degree arc to D, then holds the native right-angle construction. The CPU replays the default IGCSE `LOAD 8` instruction. Trigonometric Graphs draws the native sine trace and reveals its target crossings. The older coordinate and pattern ports are retained but are not imported by the homepage.

`HomeHero` supplies elapsed time, pause, offscreen suspension and reduced-motion behavior. Its 5.95-second scene schedule includes a 0.84-second crossfade into the next scene; native action timing is independent of the camera pass. Each plane has its own pitch, heading, depth, focal path and uniform zoom. No live lab application or iframe is loaded by the homepage.

Homepage-only backdrop overrides remove blank outer surfaces from the packet, gas, graph-search, circle and trigonometric previews. The CPU presentation and the diffraction wave field retain their native surfaces. Fixed edge masks feather the source region into the page. These overrides live separately in `HomeHero`, leaving the generated native ports intact for source comparisons.

SVG text uses geometric precision in the homepage presentation to keep labels attached to their geometry under scaling and perspective. Each scene fits a native source region before applying its camera zoom. Neither adaptation changes the native component coordinates.
