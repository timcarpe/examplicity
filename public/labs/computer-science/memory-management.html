About this execution model

One CPU core uses a simple round-robin schedule. Application work, periodic OS work and page-fault/completion handlers generate sampled memory references. Storage transfers progress alongside CPU execution. Ordinary cache/RAM misses wait within the running thread; storage-backed faults block that thread. Cache cells identify referenced pages, not whole physical pages. Work bursts, scheduling and latencies are teaching abstractions, not an instruction-accurate processor trace.
